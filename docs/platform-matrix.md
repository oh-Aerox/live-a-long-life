对应 R-21、D-17。本表如实记录每项能力在各平台上的实现和验证进度。

## 状态定义

| 状态 | 含义 |
|---|---|
| 未开始 | 还没有动手 |
| 开发中 | 正在实现 |
| 已实现待验证 | 代码完成，但还没有在真实环境中按验证方法测试 |
| 验证通过 | 已按"验证方法"在真实环境中测试通过，并在第 3 节留下证据 |
| 受阻 | 遇到了阻碍，需要写明原因和可能的替代方案 |
| 本期不做 | 明确不在当前阶段的范围内 |
| — | 不适用：该平台不需要或没有这项能力 |

**更新规则：**
- 只有在第 3 节留下对应的验证记录后，才能把状态改为"验证通过"；
- 编译通过、在模拟器上跑通，都不等于在真机上验证通过；
- 没有对应的运行环境时，状态保持不变，并在备注里写明缺少什么环境。

## 2. 安卓与 Windows 的首轮验证范围

按 Codex 3_reply 的建议，首轮只验证最关键的能力：

- **安卓首轮：** P-01、P-03、P-04、P-06、P-30 至 P-33。即通知进入、连续文字与多图保存、重启后恢复、同步。P-09 与 P-53 随医疗空间管理在 v0.4 验证，不阻塞首轮。
- **Windows 首轮：** P-30 至 P-34、P-40。即配对、接收记录和附件、常驻后台、生成/查看结果。P-53 在 v0.4 验证归档保留与取回。

**验证环境**（用户已确认有这两台设备，R-33）：

| 设备 | 品牌 / 型号 | 系统版本 | 备注 |
|---|---|---|---|
| 安卓手机 | 小米 12（2201123C） | HyperOS 3.0（OS3.0.3.0.VLCCNXM），Android 15（API 35），2026-09-29 首次连接记录；系统内置 Health Connect | 见下方"小米 12 注意事项" |
| Windows 电脑 | — | Windows 11，具体版本号待首次验证时记录（设置 → 系统 → 系统信息） | 见下方"Windows 11 注意事项" |

**小米 12 注意事项：**
- **Health Connect：** 安卓 14 及以上系统内置；安卓 13 及以下需要从 Google Play 安装，国行系统没有 Google 服务时可能装不上。首次验证时先确认系统里有没有"健康数据共享"（Health Connect）入口，没有就把 P-10 至 P-14 记为"受阻"，改为完全通过对话记录。
- **后台限制：** 小米系统会主动清理后台应用，可能导致提醒不响、后台同步不发生。验证 P-01 和 P-35 前，需要在应用设置里打开"自启动"，并把省电策略设为"无限制"。这些设置步骤要写进安卓版的首次使用引导。
- **定时提醒权限：** 安卓 12 起，准时提醒需要"闹钟和提醒"权限，要在应用里引导用户开启。

**Windows 11 注意事项：**
- 电脑连接的 WiFi 要设为"专用网络"，设为"公用网络"时，局域网发现（P-30）会被系统拦截。
- 第一次运行时，Windows 防火墙会询问是否允许访问网络，需要勾选"专用网络"。

安卓调试安装不需要付费账号，开启开发者选项后，通过 USB 或无线调试安装即可。
