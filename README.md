# 长命百岁（Live a Long Life）

[English](README.en.md)

长命百岁是一款本地优先的个人健康记录应用。它像聊天一样收集你每天的饮食、睡眠、心情、不适和运动，自动整理成结构化记录；把病历、检验单、检查报告变成可核对、可追溯到原件的数据；在电脑上生成周报，帮你看清长期的变化。

数据保存在你自己的设备上。手机负责记录，电脑负责分析和归档，两者在同一个局域网内加密同步。是否使用模型、使用哪家的模型、模型跑在本机还是云端，都由你决定。

## 功能

### 日常记录（iPhone）

- **像聊天一样记录**：连续发文字、多张照片或 PDF，每条立即保存；可以修改或删除，修改历史保留。
- **主动回顾**：按你设定的时间提醒回顾当天，只问还没记下的内容（早饭吃了什么、昨晚几点睡、今天有没有运动……）。
- **自动整理**：模型把消息整理成饮食、睡眠、心情、不适、运动、笔记等记录；"昨天忘了说的"会记到昨天。每条记录都能找回原话和照片，你改过的字段不会被再次覆盖。
- **读取苹果健康**：睡眠、步数、体能训练、活动能量作为补充，减少手动输入；你亲口说的内容优先。
- **按日查看**与逐条修正记录；不要的记录可以删除，删除时可以选择连原消息一起删。
- **个人资料**逐步收集（出生年月、性别、身高、运动偏好、慢性病、过敏等），每一项都可以跳过。
- **导出与恢复**：导出为 JSON 加文件夹（带文件清单），可以从导出恢复，包括病例夹、体检和咨询记录。安卓上也可以直接选别的设备导出后压缩成的 zip 恢复。恢复后手机再同步时，Mac 首页会提示重建副本：确认后先自动备份，再以手机现有的数据为准重新接收。

### 病历与检查单（iPhone）

- **病例夹与体检**：拍照、从相册选择或导入 PDF，列表按就诊或体检日期排列。提取时模型会按单据给每次就诊起个标题（比如"甲状腺结节复查""急性胃肠炎"），列表上直接看出是为什么去的，标题也可以自己改。重复上传时会提醒；同一张纸重拍、重新导出（字节不同）也能按识别出的内容认出来。
- **先预览，再发送**：在本机完成文字识别（Apple Vision，PDF 有文字层时直接读取），自动遮蔽姓名、证件号和门诊卡号；把将要发给模型的全部文字逐行展示给你，可以修改或删行，也可以多选批量删除（修改随文件保存，下次重新提取时自动恢复），确认后才发送。页数多的体检报告会自动分批整理。除非你主动选择下面的"模型识图"，图片不会发给模型。
- **模型识图兜底**：手写、拍歪、版式复杂、本机识别不准的报告，可以手动选择"用模型识图"：先在图上框出要识别的部分，把姓名等区域留在框外，只有框里的图片会发给支持图片的模型，裁剪图用完即弃。
- **模型整理文字**：超声等报告常把同一部位的描述和结论拆成两条，体检报告的汇总和明细也会重复。可以点"用模型整理"，把已提取的诊断与检查文字发给模型，同一部位的合成一条、重复的去掉，原文不改写；只发这些文字，不发图片。合并出来的条目要重新核对，可以撤销。
- **结构化提取**：检验数值（项目、结果、单位、参考范围、异常标记）、诊断与检查文字（主诉、诊断、处理意见、超声所见和结论等）、处方药品、身体状况建议。模型会根据上下文修正识别错字，并逐处列出修正供你核对。
- **逐项核对**：所有提取结果默认"未核对"，你确认或修改后才参与分析；诊断与检查文字、检验结果、处方药品里不需要的条目（比如空的备注栏）可以逐条删除。每个数值、每段文字都能跳回原件，并在对应位置显示高亮框。识别出的医疗机构、检查日期不对可以直接改，没识别出来的可以补填；改过的重新提取也不会被覆盖，检查日期改了，指标趋势和身体状况按新日期排。
- **长期状况档案**：区分长期状况（结石、慢性病、过敏等）和临时疾病。复查、康复以追加方式记录，既往诊断和当时的指标不会被改写。不同年份报告里的同一问题归成一行，显示最新那份报告的写法，也能打开以前报告的原件。
- **指标趋势与就诊时间线**：同一检验项目按检查日期画出变化曲线，并标出参考范围；不同医院、不同年份的写法（比如"淋巴细胞比值"与"淋巴细胞百分数"）归为同一项，项目名前表示检验结果互认的"*"也不影响，小数比值换算成百分数再画。列表按检查大项（血常规、尿常规、肝功能……）分组，尿常规的白细胞、葡萄糖、胆红素等和血里的同名项目分开，人体图上归到肾和膀胱；早先提取的报告、或长报告分批提取时漏标的，可以在详情页用模型补上大项（只发项目名称和已有的大项，不发数值）；症状、就诊、检查按时间排列。
- **人体图**：首页底栏正中的彩色人体入口。全身图上点头颈部、胸部、腹部或盆腔，画面拉近到这一块，器官标签排在两侧，用指引线指到对应位置；盆腔按资料里的生理性别显示男女不同的器官，右上角也可以切换。有需要关注的内容时标签上会显示条数，红色表示已核对、橙色表示待核对：包括最近一次仍异常的检验数值、报告里的异常描述、未解除的身体状况，以及近 30 天的身体不适。同一个问题只算一次：体检报告汇总和明细各写一遍的会合并，不同年份的报告写了同一个问题（比如脂肪肝从轻度到中度）按最新的算，以前的写法列在「此前」里。点标签列出具体内容，每条都能跳回原文件。血脂、血糖、血常规等不对应单个器官的，归在图下方的「血液与代谢」；认不出部位的归在「其他」。
- **手机空间清理**：原件已在电脑上归档后，可以清理手机上的副本释放空间，提取出的数据、核对状态、来源定位全部保留；需要时再从电脑取回。

### 主动咨询（iPhone、Mac）

- 临时想问的健康问题可以直接问模型。默认只附带基本资料和你确认过的身体状况；"最近 7 天记录摘要"需要勾选才会附带。
- 咨询不会变成健康记录；回复按格式显示。模型不做诊断、不给用药方案，需要就医时会明确建议。

### 电脑端（Mac、Windows）

- **完整副本**：保存手机同步来的全部消息、记录和原件，只读不改。
- **周报**：用 Mac 上配置的模型生成每周总结和下周建议，每条事实陈述都可以点回来源记录；手机上可以拉取查看。
- **病例与健康档案**：只读查看病例夹、体检、长期状况档案、指标趋势、就诊时间线，并对照归档的原件。
- **加密备份**：按文件清单生成加密整包，校验通过后才算可用；可以做恢复演练。备份密码只存在本机的系统加密存储里（Mac 钥匙串；Windows 用凭据管理器保管的密钥加密）。
- **扫码配对**：手机扫描 Mac 上的二维码，建立双向认证的加密连接，之后在同一局域网内自动增量同步，支持断点续传。Mac 换了 IP 地址时，手机会在局域网里自动找到它（Bonjour），不用重新配对。
- **常驻菜单栏 / 系统托盘**：关掉主窗口后应用留在 Mac 菜单栏或 Windows 任务栏右下角的托盘里，照常接收手机同步；菜单里显示最近一次同步，可以重新打开窗口或退出。Windows 只运行一个实例，安装时可选开机自启（只留托盘图标，不弹窗口）。

## 隐私与数据

- **本地优先**：数据存在设备本地的 SQLite 数据库里，没有应用自己的服务器。
- **同步只在局域网**：手机与 Mac 双向认证、全程加密。
- **模型由你选择**：支持 OpenAI、Anthropic、DeepSeek、Kimi、智谱 GLM、Ollama（本机或局域网）和任意 OpenAI 兼容服务，只需填 Base URL 和 Key。每个模型标明数据边界（本机、局域网、云端），本机模型不可用时绝不会自动改用云端。模型暂时连不上时，消息照样保存，对话里会提示"当前模型不可用"，日历视图里先列出当天待整理的原文，模型恢复后自动补整理。API Key 只存在系统钥匙串里。
- **发送内容可查**：每一次模型调用都会记录发送了什么、返回了什么、遮蔽了几处，可以在"模型调用记录"里查看。
- **未核对不算事实**：模型推断的内容在你确认前不参与分析。

## 构建与运行

需要 Flutter 3.38 或更高版本（Dart 3.10）、Xcode，以及一个 Apple 开发者账号（免费账号即可）。

```bash
cd app
flutter pub get
dart run build_runner build --force-jit --delete-conflicting-outputs  # 生成数据库代码
flutter test                                                           # 运行测试
```

**安装到 iPhone**：连接手机后运行 `./scripts/resign-install.sh`。脚本会构建、签名，并覆盖安装，保留原有数据。不要用 `flutter install`，它会先卸载应用、清掉数据。签名到期前，再运行一次脚本即可续期。

**运行 Mac 端**：

```bash
cd app
flutter build macos --debug
open build/macos/Build/Products/Debug/live_a_long_life.app
```

首次使用时，在 Mac 的"设置 → 手机连接"里显示二维码，用手机的"设置 → 连接 Mac"扫码配对。

**运行 Windows 端**：在 Windows 上 `cd app && flutter run -d windows`。打安装包需要 VS C++ 工具和 Inno Setup 6.5+，在 Git Bash 里运行 `./scripts/windows-package.sh`，产物在 `app/build/windows/installer/`；安装到当前用户目录，不需要管理员权限，覆盖安装和卸载都不动用户数据。已安装的版本在托盘里运行时，再启动（包括 `flutter run`）只会叫回已有窗口，调试前先从托盘退出。

**常见问题**：安装时提示 framework 签名无效，或者安装后打开是空白页，一般是原生组件的构建缓存残留，在 `app/` 下运行 `flutter clean` 后重新构建即可。

## 项目结构

```
app/                 Flutter 应用（iPhone、安卓、Mac 与 Windows 共用一套代码）
  lib/data/          数据库表、仓库、时间与字段元数据
  lib/services/      整理、提取、脱敏、同步、备份、分析、咨询等服务
  lib/ui/            页面
  ios/ macos/        平台工程（Apple Vision 文字识别在这里实现）
  android/           安卓工程（ML Kit 文字识别、局域网发现）
  windows/           Windows 工程（系统托盘、局域网广播）
  test/              单元测试与组件测试
docs/                需求、设计决策、数据模型、产品规格、提示词、平台验证记录
scripts/             一键重签安装脚本、Windows 打包脚本、人体图抠图脚本
```

设计文档从 [docs/README.md](docs/README.md) 开始阅读；发给模型的全部提示词见 [docs/prompts.md](docs/prompts.md)。

## 说明

长命百岁只做个人健康记录和纵向趋势分析，不提供医疗诊断。任何健康问题请以医生的意见为准。
